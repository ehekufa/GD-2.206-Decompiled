# Geometry Dash for Derka

Клон Geometry Dash на **чистом C99** для Android (8–15, arm64/arm32/x86_64).
Без Java, без Gradle, без ассетов, без кодогенерации: два файла C + манифест + иконка.

| файл | что внутри |
|---|---|
| `gd_core.c` / `gd_core.h` | уровень, физика, столкновения. Ноль системных заголовков — собирается и на хосте |
| `game.c` | оболочка: `native_app_glue` + EGL + OpenGL ES 2, всё рисуется процедурно одним `glDrawArrays` |
| `AndroidManifest.xml` | `android.app.NativeActivity`, `hasCode="false"` — Java-кода нет вообще |
| `res/drawable/ic_launcher.png` | иконка, сгенерирована процедурно |

## Как в оригинале

- физика тикает **240 раз в секунду**, скорость куба — **10.386 блока/с** («normal»),
  прыжок ≈ **2 блока вверх / 4.5 блока в длину**;
- хитбокс шипа заметно меньше картинки, у блока честный AABB, на блок можно сесть сверху;
- куб крутит один оборот за прыжок и доворачивается до 90° на земле;
- удержание кнопки = повторный прыжок при приземлении;
- смерть → осколки, тряска, вспышка и авто-рестарт, попытка N показывается в уровне;
- прогресс-бар и проценты сверху, лучший результат запоминается в сессии.

Уровень (`~1000` блоков, ~99 с) генерируется детерминированно из набора паттернов
(шипы 1–2 в ряд, блоки, площадки, «потолок», лестница-пирамида) со ступенчатой сложностью.

## Проверка на хосте (без Android)

```bash
gcc -std=c99 -O2 -DGD_SIM game/gd_core.c -o /tmp/gdsim -lm
/tmp/gdsim 0        # автопилот должен пройти уровень за 1 попытку
/tmp/gdsim -0.6     # автопилот, который опаздывает с прыжком на 0.6 блока
```

Автопилот доказывает, что уровень вообще проходим, а запуск с отрицательным/положительным
сдвигом проверяет запас по таймингу (честность уровня для живого человека).
CI делает то же самое на каждом пуше.

## Сборка APK

`.github/workflows/build-apk.yml`: NDK r25c → `libgd_derka.so` для трёх ABI →
`aapt package` (без Gradle!) → `zipalign` → `apksigner`. Ключ берётся из секретов
репозитория (`GD_P12_BASE64`, `GD_P12_PASSWORD`, опционально `GD_KEY_ALIAS`; фолбэк —
старые `CB4_*`). Если секретов нет, CI подписывает одноразовым отладочным ключом:
APK ставится на устройство, но для сторов нужно добавить свои секреты. Артефакт — `Game.apk`.

## Smoke-тест на эмуляторе

`tools/smoke.sh` ставит APK на эмулятор (API 34, x86_64), запускает активити и проверяет,
что игра действительно поехала, а не показала чёрный экран:

1. ждёт `sys.boot_completed` и сервис `package`, ставит APK (до 5 попыток);
2. ждёт в logcat строку `GL ready WxH` — её пишет `game.c` сразу после `eglMakeCurrent`,
   то есть EGL/GLES-контекст реально создан;
3. 12 секунд следит, что процесс жив;
4. снимает `adb exec-out screencap` и прогоняет через `tools/screenstat.py` — тот считает
   число цветов и долю доминирующего, отличая настоящий кадр от однотонной заливки.

Отчёт (логи, замеры pid, ASCII-карта яркости экрана) уходит в **сводку задания**
и в артефакт `smoke-report` вместе с `screen.png` и полным `live.log`.
Красная аннотация появляется, только если игра не поднялась.

Управление: тап по экрану / пробел / D-pad.
