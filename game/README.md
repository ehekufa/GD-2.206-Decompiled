# Geometry Dash for Derka

Клон Geometry Dash на **чистом C99** для Android (8–15, arm64/arm32/x86_64).
Без Java, без Gradle, без ассетов, без кодогенерации: два файла C + манифест + иконка.

| файл | что внутри |
|---|---|
| `gd_core.c` / `gd_core.h` | каталог объектов, физика 8 режимов, орбы/пады/порталы, триггеры, модель редактора, аккаунты, сохранения. Ноль системных заголовков — собирается и проверяется на хосте |
| `game.c` | оболочка: `native_app_glue` + EGL + OpenGL ES 2, всё рисуется процедурно одним `glDrawArrays`. Меню, список уровней, страница уровня, гараж, аккаунты, настройки, редактор, игра, экран прохождения |
| `AndroidManifest.xml` | `android.app.NativeActivity`, `hasCode="false"` — Java-кода нет вообще |
| `res/drawable/ic_launcher.png` | иконка, сгенерирована процедурно |

## Что перенесено из Geometry Dash

**Физика** — 240 тиков в секунду, `normal speed` 10.386 блока/с, скорости 0.5x/1x/2x/3x/4x/5x
(0.815/1/1.263/1.574/1.944/2.357), прыжок куба ≈ 2.21 блока в высоту и 4.49 в длину,
хитбокс шипа заметно меньше картинки, у склона честная поверхность (по нему можно ехать),
поворот куба — один оборот за прыжок с доворотом до 90° на земле.

**8 режимов**: куб, корабль, шар, UFO, волна, робот (тянущийся прыжок), паук (телепорт
на противоположную поверхность), свинг. Плюс гравитация вверх/вниз, мини-размер,
дуал (два игрока с обратной гравитацией), зеркало, телепорт-порталы, потолок уровня.

**Орбы** (жёлтый, розовый, красный, синий, зелёный, чёрный, дэш, розовый дэш, паук,
триггер-орб) и **пады** (жёлтый, розовый, красный, синий, дэш). Орб срабатывает по
нажатию, пад — от касания.

**29 триггеров**: Move, Rotate, Scale, Alpha, Color, Pulse, Spawn, Touch, Count,
Instant Count, Collision, Toggle, Show, Hide, Stop, Follow, Follow Player Y,
Move Target, Kill, End, Shake, Flash, Camera Offset, Zoom, Particle, Pickup,
Sequence, Random. У Move — цель-группа, X/Y в юнитах GD (30 юнитов = 1 блок),
время и easing (9 видов из списка GD).

**Letter-блоки D/J/S/H/F** (вкладка Special) — по описанию с Geometry Dash Wiki:
D гасит урон волны о платформы, J запрещает авто-прыжок при удержании, S останавливает
дэш-орбы, H убирает урон сверху, F переворачивает гравитацию при ударе о блок сверху.

**Редактор уровней** — 13 вкладок каталога (нумерация как в GD: Блоки=1 … Триггеры=13),
постановка с привязкой к сетке, выделение (тап и рамка), перемещение, поворот, масштаб,
флип, группы, copy/paste, undo, удаление, редактирование 8 параметров любого объекта,
пан/зум, тест уровня и сохранение.

**Аккаунты** — регистрация и вход (локальная база, пароль хэшируется FNV-1a с солью
ника), экранная клавиатура, статистика (звёзды, орбы, демоны, монеты), гараж: иконка,
основной/вторичный цвет, glow — отдельно для каждого из 8 режимов. Всё пишется в
`internalDataPath/gd_derka.sav`, уровни сериализуются в текстовом формате `GD1;…`
(ключи 1/2/3/6/57 — как в строке уровня GD).

**Меню**: главное (Play / Creator / Garage / More / аккаунт), список уровней с
прокруткой, страница уровня (Play / Practice / Edit / Delete), пауза, экран прохождения
с попытками, прыжками, кликами и монетами. Практика — с чекпоинтами.

## Проверка на хосте (без Android)

```bash
bash tools/hostcheck.sh
```

Скрипт делает три вещи обычным gcc:

1. `gcc -DGD_SIM game/gd_core.c` и два запуска автопилота (`0` и `-0.6` — опоздание
   прыжка на 0.6 блока): автопилот обязан пройти все демо-уровни без смертей, иначе
   уровень нечестный;
2. компиляция `game.c`;
3. прогон оболочки на стабах OpenGL (`tools/hoststub/`, `tools/ui_harness.c`):
   рисуются меню, список уровней, страница уровня, гараж, аккаунт, настройки,
   редактор с попапом триггера, игра, пауза и экран прохождения; попутно создаётся
   аккаунт, ставятся все объекты каталога и проходится уровень с порталами.

Отдельно юнит-тесты ядра проверяют высоту прыжка, скорость, каждый тип орба и пада,
все порталы, Move/Rotate/Alpha/Color/Pulse/Pickup/Count/Spawn/Show/Toggle-триггеры,
операции редактора, round-trip строки уровня, регистрацию/вход и сохранения.

## Сборка APK

`.github/workflows/build-apk.yml`: NDK r25c → `libgd_derka.so` для трёх ABI →
`aapt package` (без Gradle!) → `zipalign` → `apksigner`. Ключ берётся из секретов
репозитория (`GD_P12_BASE64`, `GD_P12_PASSWORD`, опционально `GD_KEY_ALIAS`; фолбэк —
старые `CB4_*`). Если секретов нет, CI подписывает одноразовым отладочным ключом:
APK ставится на устройство, но для сторов нужно добавить свои секреты. Артефакт — `Game.apk`.

Управление: тап по экрану / пробел / D-pad; в редакторе — тап ставит объект,
перетаскивание двигает камеру или выделение.
